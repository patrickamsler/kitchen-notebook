# ADR-008 Sign-in UI: Keycloak theme vs Angular screens

## Context and Problem Statement

The designs show custom sign-in, sign-up and invite screens. With standard OIDC these are Keycloak pages; fully custom
Angular screens would need non-standard flows.

## Considered Options

- Theme Keycloak to match the design (e.g. Keycloakify)
- Accept Keycloak's standard pages, styled lightly
- Custom Angular screens with non-standard flows

## Decision Outcome

Open.
