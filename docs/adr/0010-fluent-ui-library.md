# ADR-010 Fluent 2 look in Angular: library choice

## Context and Problem Statement

The design follows a Fluent 2-inspired look (see `docs/design/design-system.md`). Which component implementation?

## Considered Options

- Fluent UI Web Components in Angular
- Angular Material / CDK themed to Fluent tokens
- Own components on Angular CDK

## Decision Outcome

Open. Until decided, plain components styled with `kn-tokens.css`.
